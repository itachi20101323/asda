## 🌌 About CartNova

**CartNova** is a next-generation frontend e-commerce interface designed for absolute peak performance and visual dominance. Leaving boring, static storefronts in the past, CartNova leverages **glassmorphism, advanced micro-interactions, neon holographic styling, and raw Vanilla JavaScript** to create an immersive, zero-latency shopping experience. 

Whether you are browsing products, interacting with the cart, or navigating the UI, every click and hover is engineered to feel alive.

| Layer | Implementation | Status |
| :--- | :--- | :--- |

*   **Liquid Neon Buttons:** Call-to-action buttons that pulse with high-contrast gradients.
*   **Dynamic Cart Drawer:** Smooth, high-FPS sliding side-cart for seamless state management without reloading.
*   **Skeleton Loading:** Premium skeleton screens to ensure UI stability before assets fully render.
